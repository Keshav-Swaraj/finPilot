# Welth - AI Finance Platform

Welth is an intelligent, one-stop finance platform designed to help you manage your finances smarter. Built with Next.js, Prisma, and Tailwind CSS.

## Features

- **Advanced Analytics**: Get detailed insights into your spending patterns with AI-powered analytics.
- **Smart Receipt Scanner**: Extract data automatically from receipts using advanced AI technology.
- **Budget Planning**: Create and manage budgets with intelligent recommendations.
- **Multi-Account Support**: Manage multiple accounts and credit cards in one place.
- **Automated Insights**: Get automated financial insights and recommendations.

## Tech Stack

- **Frontend**: Next.js 15, React 19, Tailwind CSS
- **Backend & Database**: Next.js API Routes, Prisma ORM, PostgreSQL
- **Authentication**: Clerk
- **UI Components**: Radix UI, shadcn/ui
- **Other Tools**: Inngest, Resend

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/Keshav-Swaraj/finPilot.git
   ```
2. Install dependencies:
   ```bash
   npm install --legacy-peer-deps
   ```
3. Setup environment variables (create a `.env` file):
   - `DATABASE_URL`
   - `DIRECT_URL`
   - Clerk API keys, etc.
4. Run the development server:
   ```bash
   npm run dev
   ```
